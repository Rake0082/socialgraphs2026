# Character photos (optional)

Drop an image here and the landing page uses it instead of the drawn placeholder.

File name = the character slug:

| Character              | File name                    |
|-----------------------|------------------------------|
| Spider-Man            | `spider-man.jpg`             |
| Hulk                  | `hulk.jpg`                   |
| Wolverine (character) | `wolverine-character.jpg`    |

`.jpg`, `.jpeg`, `.png` and `.webp` all work. Recommended size ~600×750 (4:5).

**Copyright:** do not use Marvel artwork, movie stills, or game covers — those are
not free to redistribute on a public site. Use your own artwork, or a
Creative-Commons-licensed cosplay photo from Wikimedia Commons (and add the
attribution the licence requires, e.g. in the page footer).
